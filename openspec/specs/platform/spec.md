## Note on SPEC_INDEX.md

The legacy `SPEC_INDEX.md` listed all spec files in a flat table. That function is now served by this OpenSpec domain structure. When looking for a spec, use `openspec view` or navigate the `openspec/specs/` domain folders directly.
