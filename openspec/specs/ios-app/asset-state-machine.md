# Asset State Machine

Defines lifecycle states for assets generated by Polly skills (images, components, design tokens).

---

## States

```
draft → staged → approved → library
              ↘ rejected
```

| State | Description | Visible to User |
|-------|-------------|-----------------|
| `draft` | Generated by skill, not yet surfaced | No |
| `staged` | In review queue, awaiting user decision | Yes — staging view |
| `approved` | User confirmed | Brief toast confirmation |
| `library` | Available in asset picker | Yes — asset library |
| `rejected` | Discarded by user | No (retained in rejected bucket, auto-purged 30 days) |

---

## Transitions

| From | To | Trigger |
|------|----|---------|
| `draft` | `staged` | Skill completes generation, gateway pushes `asset.staged` event |
| `staged` | `approved` | User taps "Approve" in staging view |
| `staged` | `rejected` | User taps "Reject" in staging view |
| `approved` | `library` | Automatic on approval |
| `rejected` | (purged) | 30-day TTL |

---

## WebSocket Event Shape

```json
{
  "event": "asset.staged",
  "assetId": "<uuid>",
  "type": "image | component | token",
  "previewType": "image | render-frame | swatch-grid",
  "previewUrl": "<gateway-relative-url>",
  "generatedBy": "<skill-id>",
  "agentId": "<agent-id>",
  "timestamp": "<ISO 8601>",
  "metadata": {
    "inputParams": {},
    "skillVersion": "1.0.0"
  }
}
```

Additional events: `asset.approved`, `asset.rejected`, `asset.purged` — same shape, different `event` value.

---

## Storage

Assets stored in per-skill workspace: `~/.openclaw/skills/<skill-id>/assets/<asset-id>/`

- `asset.json` — metadata + current state
- `preview.*` — preview file (image, SVG, JSON tokens)

Asset state transitions are append-logged for audit trail.

---

## Rejected Asset Retention

Rejected assets are retained for 30 days before auto-purge. Not surfaced in the main UI but accessible via gateway API for debugging/audit. Auto-purge runs as a scheduled gateway cron.
