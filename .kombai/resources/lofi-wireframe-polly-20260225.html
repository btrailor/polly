Polly App — Redesign Wireframe
Addresses: navigation overload, design system consistency, duplicate nav, font readability, skeleton loading, settings cleanup

Key Design Issues Addressed in This Wireframe

✓ Ribbon: 13 unlabelled icons → Grouped with labels
Icons grouped into sections (Core, Workspace, Tools) with short text labels always visible at 10px. Reduces cognitive load.
✓ Duplicate sidebar nav removed
Left sidebar now shows contextual content only (conversation list, notes list, etc.) — no longer mirrors ribbon navigation.
✓ Dashboard stats use skeleton loader
Stat cards show skeleton shimmer while loading instead of "–" placeholder text. Uses existing skeleton-loader.js.
✓ Mixed font stack: mono + sans-serif
UI labels and descriptions use system-ui. Monospace kept for headers, code, and terminal elements only.
✓ Domain cards: keyboard-accessible
Domain cards rendered as buttons with role="button", tabindex, and visible focus ring instead of plain divs.
✓ Settings: single layout, no legacy tabs
Settings shown in two-column layout (nav + content) without legacy tab-general / tab-routing blocks.
