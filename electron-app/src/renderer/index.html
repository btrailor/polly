Semantic Cache

                  

                    Cache responses for semantically similar queries to reduce latency and LLM costs.
                    When a new query closely matches a cached one, the stored response is returned instantly
                    without calling the LLM.

Context Persistence

                  

                    Polly's rolling context window tracks which topics and memories are active in the current session.
                    When enabled, this context is saved to disk at session end and restored on the next startup —
                    so Polly remembers what you were working on without you having to repeat yourself.
                  


                  

                    

                      
                      
                    

                    
Save and restore the active context window between sessions. Requires restart to take effect.

                  


                  

                    

                      

                        
                        12h
                      

                      
                      
Context entries decay when the gap between sessions exceeds this threshold (1–72 hours). Shorter = faster forgetting on long breaks.

                    

                  

                


                
                

                  
Mental Model Format

                  

                    Mental models are injected into each query as compressed context.
                    Compact uses symbol substitution (~8 tokens per model) but may not be parsed
                    correctly by small local models. Full text uses ~50 tokens but is reliably
                    interpreted by all models. Auto (A/B) tests both formats and automatically
                    switches to the better-performing one per model after 50 turns.
                  


                  

                    

                      
                    

                    

                      
                      
                      
                    

                    
Static per-model profiles (qwen → full text, claude/gpt → compact) apply when Auto is off and A/B data is insufficient.

Retrieval Tier Thresholds

                  

                    Every query is classified as Direct, Adjacent, or Absent based on how closely your knowledge base matches it.
                    Direct means Polly answers locally from your notes. Lowering the Direct threshold makes it easier for saved knowledge to be used.
                  


                  

                    

                      
                      0.72
                    

                    
                    
Minimum similarity score to classify a result as a Direct (high-confidence) match. Lower = more queries answered from your knowledge base.

                  


                  

                    

                      
                      0.50
                    

                    
                    
Minimum score for Adjacent (related but not a direct answer). Results below this are considered Absent.

                  


                  

                    

                      
                      0.10
                    

                    
                    
Score bonus added when a result comes from the same domain as the query (0–0.30).

                  


                  

                    

                      
                      0.15
                    

                    
                    
Score penalty applied when a result comes from a different domain (0–0.30).

                  

                


                

                  
Query Decomposition (Wave 3)

                  
Complex queries are automatically broken into sub-queries and routed in parallel — some to local, some to cloud — then synthesised into one answer.


                  

                    

                      
                      
                    

                    
When enabled, multi-part or analytical queries are decomposed and routed via the Wave 3 hybrid pipeline.

                  


                  

                    

                      
                      0.60
                    

                    
                    
Score above which a query is considered complex enough for decomposition (0–1). Lower = more queries decomposed.

                  

                


                
                

                  
BM25 Index Persistence

                  

                    Hybrid search uses a BM25 keyword index alongside semantic search.
                    Without persistence, this index is rebuilt from scratch on every session start
                    (2–10 seconds for large knowledge bases). When enabled, the index is saved to disk
                    and loaded instantly on subsequent sessions.
                  


                  

                    

                      
                      
                    

                    
Save the keyword search index to ~/.polly/bm25_index.pkl after each build. Automatically invalidated when your knowledge base changes. Requires restart to take effect.

🔀 Hybrid Routing

                
Control when Polly uses local models (Ollama) vs cloud providers (GitHub/OpenAI/Anthropic).

                

                  How it works: When you ask a question, Polly searches your knowledge base (RAG). 
                  If it finds strong, relevant context, it uses your free local Ollama model. 
                  For complex queries or weak context, it routes to cloud providers for better reasoning.

Semantic Compression Trigger

                

                  Instead of compressing only when a message count or age threshold is reached,
                  semantic compression measures how redundant the current context has become.
                  When enabled, compression fires when the conversation becomes semantically repetitive —
                  preserving useful context longer and compressing noise sooner.
                

                

                  
                  
Trigger compression based on semantic redundancy (SRS score) instead of message count alone. Falls back to message count if embedding is unavailable.

                

                

                  

                    
                    
                    
Semantic Redundancy Score above which compression is triggered. Default: 0.75

                  

                  

                    
                    
                    
If SRS can't be computed, fall back to compressing after this many messages. Default: 30

                  

                


                
RAG / Context Compression

LLMLingua reduces token count; LLM summary uses model-generated summaries.

Default: 0.5 (e.g. 2× compression)

                    What are Mental Models?
                  

                  

                    Mental models are meta-instructions that shape how Polly behaves. They encode aesthetic standards 
                    (like Hyper-Minimalism and Readability Ratchet), decision-making frameworks (Constraint-Based Filter, 
                    Compound Question), workflow patterns (Continuation Probe, Context Capture), and cross-domain wisdom.
                  

                  

                    Activation: Models activate automatically based on your current domain, page, and active persona. 
                    For example, the Programmer persona activates "Readability Ratchet" to write clear, maintainable code with 
                    2-space indentation and snake_case naming.
                  

                


                
                

                  

                    Default Models
                  

                  

                    Choose specific mental models to always use. When enabled, these override the automatic
                    context-based selection for all conversations (unless a conversation has its own override).
